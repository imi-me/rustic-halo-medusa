# Storefront display type

`CormorantGaramond-variable.ttf` is locally hosted for consistent light serif
headings matching the approved homepage concept. It is sourced from the official
Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

The accompanying `CormorantGaramond-OFL.txt` contains the SIL Open Font License.
The storefront does not make runtime requests to Google Fonts.
